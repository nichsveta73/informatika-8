Стартове запитання: що відбувається всередині комп’ютера, коли ти відкриваєш браузер або запускаєш гру?

1. Чому комп’ютери працюють по-різному?

Навіть якщо на двох комп’ютерах установлена однакова програма, швидкість її роботи може відрізнятися. Причина — у характеристиках складових та в тому, як вони взаємодіють.

  • Чи достатньо мати просто великий обсяг пам’яті?
  • Що станеться, якщо прибрати оперативну пам’ять?
  • Які характеристики важливі для навчання, ігор або роботи з відео?

2. Основні складові системного блока

🧠 Процесор (CPU)

обробка

тимчасова пам’ять

зберігання

3. Процесор: «мозок» комп’ютера

Процесор виконує інструкції програм, виконує арифметичні та логічні операції й обмінюється даними з іншими компонентами.

ХарактеристикаЩо означає?
Кількість ядерКількість обчислювальних ядер, які можуть виконувати роботу паралельно.
Тактова частота, GHzЧастота роботи процесора. Більше число саме по собі не гарантує вищу продуктивність.
КешШвидка пам’ять процесора для часто потрібних даних та інструкцій.
Архітектура та енергоефективністьВпливають на продуктивність, споживання енергії та тепловиділення.
Важливо: 3,5 GHz не означає буквально «3,5 млрд інструкцій за секунду». Реальна продуктивність залежить від архітектури, кількості ядер, типу завдання, охолодження та інших чинників.

4. Пам’ять: RAM, ROM, SSD, HDD

ТипПризначенняЧи зберігаються дані без живлення?
RAMТимчасова робоча пам’ять для запущених програм і даних.Ні, зазвичай вміст втрачається.
ROM / firmwareМістить інструкції для початкового запуску та роботи пристрою; сучасна прошивка зберігається у флеш-пам’яті.Так.
SSDДовготривале зберігання файлів і програм; флеш-пам’ять, без рухомих частин.Так.
HDDДовготривале зберігання даних на магнітних дисках.Так.

Запам’ятай: RAM потрібна для роботи «зараз», SSD/HDD — для зберігання «надовго».

7. Практика «Комп’ютер для замовника»

Обери ситуацію та запропонуй характеристики комп’ютера. Не потрібно називати конкретну модель — обґрунтуй свій вибір.

🏫 Комп’ютер для навчання

Браузер, документи, презентації, онлайн-уроки.

🎮 Комп’ютер для ігор

Сучасні 3D-ігри та плавне відтворення зображення.

🎨 Комп’ютер для творчості

Обробка фото, відео та графіки.

💼 Комп’ютер для офісу

Документи, таблиці, відеозв’язок, друк.
