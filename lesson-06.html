3. Хід уроку

І. Організаційний момент. Мотивація — 4 хв

Проблемна ситуація «Невдала покупка».

Андрій придбав дорогий ігровий комп'ютер, але використовує його лише для перегляду відео, роботи з документами та навчання. Марія придбала недорогий ноутбук, щоб створювати складні 3D-моделі, але програми працюють дуже повільно.

Запитання: хто припустився помилки і чому?

Андрій витратив більше, ніж потрібно для базових завдань. Марія не врахувала системні вимоги програм для 3D-моделювання. Найкращий комп'ютер не обов'язково найдорожчий, а той, що відповідає конкретним потребам.

Проблемне запитання: чому комп'ютеру для роботи з текстовими документами не завжди потрібна потужна дискретна відеокарта?
Текстові документи майже не навантажують графічну підсистему. Для них важливі зручність, достатня RAM, швидкий SSD, екран і автономність ноутбука. Дискретна відеокарта доречна тоді, коли є графічні, 3D, ігрові або відеомонтажні завдання.

4. Практична робота № 2 — 20 хв

«ІТ-консультант: комп'ютер для клієнта»

Сюжет. Ви — консультанти магазину комп'ютерної техніки. До вас звернулися клієнти з різними потребами. Запропонуйте доцільну конфігурацію в межах бюджету й переконайте клієнта, що вона забезпечить виконання його завдань.

Оберіть картку клієнта

Кроки виконання

  1. Проаналізуйте потреби клієнта. Запишіть, для чого використовуватиметься комп'ютер, і визначте 3 найважливіші вимоги.
  2. Дослідіть характеристики. Знайдіть щонайменше два можливі варіанти або скористайтеся навчальним конфігуратором нижче.
  3. Складіть конфігурацію. Заповніть таблицю компонентів.
  4. Обґрунтуйте рішення. Напишіть короткий висновок із трьох речень.
  5. Презентуйте результат. Назвіть головні характеристики, вартість і переваги.

Навчальний конфігуратор

Ціни умовні, для вправи з вибору. Для реальної збірки потрібно перевіряти сумісність компонентів.

7. Рефлексія — «Продай свій вибір!»

Сформулюйте короткий рекламний слоган обраного комп'ютера, у якому є перевага та зв'язок із потребами клієнта.

Запитання для обговорення

  1. Який параметр був найважливішим для вашого клієнта?
  2. Від чого довелося відмовитися через обмеження бюджету?
  3. Чи завжди більша кількість ядер, RAM або дорожча відеокарта означають кращу покупку?
  4. Що ви перевірятимете перед придбанням власного комп'ютера?
Підсумкова думка: правильний вибір комп'ютера — це баланс між потребами, продуктивністю, сумісністю, зручністю та вартістю.

8. Домашнє завдання на вибір

Варіант А

«Мій ідеальний комп'ютер». Визначте 5 основних характеристик, поясніть вибір і створіть мініпрезентацію на 3 слайди.

Варіант Б

«Комп'ютер без зайвих витрат». Порівняйте два готові комп'ютери приблизно однакової вартості й оберіть кращий для навчання.

Творчий варіант

Створіть рекламний постер «Обирай комп'ютер розумно», представивши п'ять порад покупцеві.
