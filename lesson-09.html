🧩 Як браузер розуміє текст?

У текстовому процесорі ми натискаємо кнопку «Жирний». А як повідомити браузеру, що частина тексту має бути заголовком, абзацом чи списком?

Звичайний текст:

Мій клас
Ми вивчаємо інформатику.
Наші предмети: математика, інформатика.

Текст із розміткою:
<h1>Мій клас</h1>
<p>Ми вивчаємо інформатику.</p>

Поміркуй: навіщо потрібні позначки у кутових дужках? Обговоріть у парах.

Сьогодні навчимося

  • пояснювати, що таке HTML, тег та атрибут;
  • розпізнавати структуру HTML-документа й теги тексту;
  • створювати HTML-файл у Visual Studio Code та відкривати його в браузері;
  • знаходити й виправляти прості помилки в коді.

📖 Інтерактивний конспект

Що таке HTML?

HTML (HyperText Markup Language) — мова розмітки гіпертексту. Теги описують структуру вмісту сторінки. HTML — не мова програмування.

Тег — позначка в кутових дужках, наприклад <p>. Парні теги мають відкривальну й закривальну частини: <p>Текст</p>. Непарний <br> переносить рядок.

Будова HTML-документа
<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <title>Моя перша сторінка</title>
</head>
<body>
  <h1>Привіт, світе!</h1>
  <p>Це моя вебсторінка.</p>
</body>
</html>

<head> — службова інформація; <title> — назва вкладки; <body> — видимий вміст сторінки. <!DOCTYPE html>, lang і charset — сучасні корисні доповнення до базової структури.

Теги для тексту та списків
ТегПризначення
<h1>…</h1> — <h6>Заголовки різних рівнів
<p>…</p>Абзац
<b>…</b>Візуально жирне накреслення
<i>…</i>Візуально курсивне накреслення
<br>Перенесення рядка
<ul>, <ol>, <li>Маркований, нумерований список, його пункт
Що таке атрибут?

Атрибут уточнює властивість елемента. Наприклад, <html lang="uk"> указує мову документа, а <ol start="3"> починає нумерацію з 3.

У підручнику наведено історичні атрибути bgcolor і text. У сучасних сайтах кольори зазвичай задають за допомогою CSS; це вивчатимемо окремо.

💻 Створюємо вебсторінку у Visual Studio Code

Мета: створити файл my-page.html, відкрити його в браузері й переконатися, що зміни в коді впливають на сторінку.

Безпека: сиди правильно, дотримуйся комфортної відстані до монітора, роби короткі паузи для очей. Не публікуй особисті дані.
  1. Створи на комп’ютері папку HTML-8.
  2. Відкрий Visual Studio Code → File → Open Folder і вибери цю папку.
  3. У панелі Explorer натисни New File і створи my-page.html.
  4. Скопіюй початковий HTML-код кнопкою нижче та встав у файл.
  5. Зміни заголовок, абзац і список на власні. Збережи Ctrl + S.
  6. У Провіднику відкрий my-page.html подвійним клацанням у браузері. Після змін знову збережи файл і онови вкладку клавішею F5.
