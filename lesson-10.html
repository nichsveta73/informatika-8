🖼️ Зображення та гіперпосилання на вебсторінці

Досліджуємо HTML, вчимося додавати зображення та створювати посилання, перевіряємо себе і розробляємо власну міністорінку.

🎯 Сьогодні навчишся

Знатиму

  • для чого потрібні теги <img> і <a>;
  • що означають атрибути src, alt, href, target;
  • чим відрізняються абсолютні й відносні шляхи.

Умітиму

  • додавати зображення до HTML-документа;
  • створювати гіперпосилання;
  • перевіряти роботу коду в браузері;
  • дотримуватися правил безпечного використання ресурсів.
Орієнтири успіху: я можу пояснити призначення тегів, правильно записати їхні атрибути, створити сторінку із зображенням і двома посиланнями та виправити помилку в коді.

💬 Проблемне запитання

Чому браузер іноді показує значок «зламаного» зображення замість картинки, а посилання не відкриває потрібну сторінку?

📖 Досліджуємо нове

1. Як додати зображення?

Тег <img> вставляє зображення. Він не має закривального тегу. Атрибут src указує адресу файлу, а alt — альтернативний текст, який допомагає зрозуміти зміст зображення, якщо воно не завантажилося або використовується програма читання з екрана.

<img src="images/kvity.jpg" alt="Жовті квіти на галявині" width="320">

Файл kvity.jpg має лежати в папці images поряд з HTML-файлом.

Ілюстрація створена без зовнішніх файлів — працює навіть без інтернету.

Запам’ятай: назва файлу, розширення та шлях мають збігатися з реальним розташуванням зображення. Атрибут alt описує зміст, а не просто повторює слово «картинка».

2. Як створити гіперпосилання?

Тег <a> робить текст або зображення клікабельним. Атрибут href містить адресу переходу. target="_blank" відкриває посилання в новій вкладці.

<a href="https://uk.wikipedia.org/" target="_blank">Відкрити Вікіпедію</a>

Спробуй приклад: Відкрити Вікіпедію ↗

🌍 Абсолютна адреса

https://example.org/page.html

Повна адреса ресурсу в інтернеті.

📁 Відносна адреса

pages/about.html

Шлях від поточного HTML-файлу до іншого файлу сайту.

3. Зображення теж може бути посиланням

<a href="https://uk.wikipedia.org/"> <img src="images/logo.png" alt="Перейти до Вікіпедії"> </a>
Цифрова безпека: перевіряй адреси сайтів, не відкривай підозрілі посилання, поважай авторські права на зображення та зазначай джерело, якщо це потрібно за ліцензією.

📚 Пам’ятка перед практичною роботою: теги та атрибути

Пригадай, які HTML-теги й атрибути ми вивчили. Скористайся таблицею як підказкою під час виконання завдання.

Тег / атрибутДля чого потрібенПриклад
<img>Додає зображення на вебсторінку; закривального тегу немає<img src="foto.jpg" alt="Квіти">
srcУказує шлях або адресу зображення в тезі <img>src="images/foto.jpg"
altОписує зображення словами, зокрема якщо воно не завантажилосяalt="Квіти у вазі"

hrefУказує адресу сторінки, на яку веде посиланняhref="https://uk.wikipedia.org/"

Пам’ятай: src використовуємо для адреси зображення, а href — для адреси посилання. У практичній роботі достатньо простих тегів <img> та <a>; переходи до частин сторінки за допомогою id не потрібні.

📋 Покрокова інструкція до практичної роботи

Економимо час! Не потрібно набирати всю сторінку вручну. Скопіюй готовий HTML-код із редактора нижче у Visual Studio Code, а потім зміни лише потрібні частини.
  1. Створи папку moya-storinka на комп’ютері.
  2. Збережи в цій папці фотографію улюбленого місця або захоплення. Назви файл латинськими літерами, наприклад moie-mistse.jpg. Зверни увагу на справжнє розширення: .jpg, .jpeg або .png.
  3. Відкрий Visual Studio Code → File → Open Folder («Файл → Відкрити папку») → обери moya-storinka.
  4. Створи новий файл 2311.html саме в папці moya-storinka.
  5. Скопіюй готовий код із блоку «HTML-код» нижче та встав його у файл 2311.html. Збережи файл клавішами Ctrl + S.
  6. Зміни заголовок усередині <h1>...</h1> та короткий текст усередині <p>...</p>, розповівши про своє місце або захоплення.
  7. Додай власне зображення: у тегу <img> заміни довгу адресу після src= на назву свого файлу, наприклад src="moie-mistse.jpg". Після alt= напиши короткий опис того, що зображено. Фотографія та 2311.html лежать в одній папці, тому назви файлу достатньо.
  8. Зміни обидва гіперпосилання: заміни адреси в href= на адреси двох відомих сайтів (наприклад, сайту закладу освіти й освітнього ресурсу) та зміни текст посилань між тегами <a> і </a>.
  9. Перевір результат: збережи зміни (Ctrl + S), відкрий 2311.html у браузері й перевір зображення та обидва посилання.
Важливо: у готовому зразку спочатку показано малюнок гір, вбудований без окремого файлу. Не потрібно переписувати його довгу адресу. Просто заміни все значення src на назву власного фото, а значення alt — на свій опис. Не змінюй назви тегів і атрибутів.

🔴 Що обов’язково змінити у Visual Studio Code?

У зразку коду червоним кольором виділено два значення, які потрібно замінити на власні: адресу файлу зображення та його опис.

<img src="moie-mistse.jpg" alt="Моє улюблене місце" width="320">
Зверни увагу: змінюй лише текст у лапках після src= і alt=. Назви атрибутів src та alt, лапки й дужки залишаються. У src запиши справжню назву та шлях до свого файлу, а в alt — коротко опиши, що зображено.

🛠️ Спробуй у вбудованому редакторі

Готовий код уже вставлено в редактор. Натисни «Скопіювати код», встав у файл 2311.html у Visual Studio Code і редагуй там. Тут також можна спробувати зміни та переглянути результат. Вбудований малюнок у зразку потрібно замінити на своє фото.

Попередній перегляд

Посилання на зовнішні сайти відкриваються в окремій вкладці. Для власного фото відкрий 2311.html у браузері: файл фото має бути в тій самій папці moya-storinka.
